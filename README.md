# 节点商城 3.0

> 最后更新日期：2026-11-22

## 最近更新

- 到期流量重置增加规则校正：已到期用户即使本周期曾经重置，当当前总流量与管理员最新默认规则不一致时也会自动校正；未到期用户购买的额外流量不受影响。
- 用户解析登录页客户端下载链接和版本号改为完全读取后台“Windows 安装包 HTTPS 地址”与“最新版本号”，落地页新增同源“客户端”下载入口，登录后的使用教程下方新增“安装客户端”按钮。
- 用户解析登录页改为深色双卡片样式，保留顶部公告、解析登录、自助购买和二维码识别逻辑，并新增动态 Windows 客户端下载卡片。
- 删除解析登录页视频模块及管理员后台视频链接配置入口。
- 软件管理顶部新增“内置应急节点”，管理员可保存订阅链接并独立启用；客户端仅在启用时把这些节点加入中转入口选择框，并在运行中实时刷新。
- 应急订阅链接清空后保存会自动关闭应急节点并清除旧配置，客户端刷新后立即移除入口列表中的应急节点。
- 管理员后台“软件管理”优化为滚动公告与登录弹窗公告左右并排，并保留各自独立保存按钮。
- 软件管理新增在线用户状态，桌面软件每 30 秒上报心跳，后台每 15 秒自动刷新并显示用户、IP、版本、当前节点和最后活跃时间。
- 软件管理新增第三方订阅日志，仅首次记录未出现过的订阅链接，不重复写入或覆盖历史记录，并支持管理员单条删除。
- 3x-ui 主副面板同步新增醒目的启用/暂停开关，管理员关闭后暂停每 5 分钟自动同步，手动同步功能仍可继续使用。
- 软件用户在线状态改为每页 10 条并支持翻页，在线数据每 5 秒实时刷新，翻页时保持当前页不跳转。
- 第三方订阅日志改为每页 10 条并使用独立分页，删除记录后自动保持在有效页码。
- 软件管理新增版本更新发布：可设置版本号、Windows/macOS 安装包地址、更新说明、启用更新和强制更新开关。
- 已发布 Windows 客户端 v0.3.0 安装包，并启用后台版本检查；后续可直接在软件管理中替换新版下载地址。

- 管理员后台新增“软件管理”菜单，可启用、关闭并修改桌面软件顶部滚动公告；软件运行中自动同步公告内容。
- 软件管理支持远程更换软件接口域名，客户端自动保存新域名并在异常时切换备用接口。
- 软件管理新增登录用户弹窗公告，可设置每位用户展示次数；管理员重新发布后按新版本重新展示。

- 主副面板同步升级为整面板同步：无需填写入站 ID，可预览并同步全部入站、客户端、出站与路由规则；支持新增、修改和删除，执行前带配置版本校验及删除确认保护。
- 主副面板支持每 5 分钟后台自动同步，并显示最近运行时间与结果；管理员无需保持页面打开。
- 主副面板自动同步状态和最近运行时间在管理员页面每 10 秒自动刷新。
- 主副面板同步同时镜像客户端流量上限及上传、下载、已使用流量统计。

- 主副面板同步可选补齐副面板缺少的客户端，并跳过缺少备注或备注冲突的条目。

- 面板对接新增手动主副面板同步。选择已启用的面板和对应入站，预览后可将匹配 UUID 的启用状态、到期时间及流量上限同步到副面板。

- 新增管理员后台访问统计，支持真实访客 IP、访问时间、停留时间、页面名称、来源和设备信息。
- 访问统计数据及停留时间每 15 秒自动刷新。
- 修复 Cloudflare 与 VPS 反向代理场景下访客 IP 被记录为服务器 IP 的问题。
- 修复着陆页顶部外部图床链接在部分网络环境无法显示的问题，改为网站同源安全代理加载。
- 访问统计新增单条记录删除功能；补充 sitemap、canonical 与搜索引擎抓取规则。
- 管理员登录页和后台不再加载或显示悬浮在线客服组件。
- 优化着陆页搜索标题、描述、核心关键词和结构化数据，并接入 IndexNow 主动提交。
- 添加百度搜索资源平台首页所有权验证标签。
- 添加搜狗站长平台首页所有权验证标签。
- 添加神马搜索站长平台首页所有权验证标签。
- 访问统计清理支持选择 7、30、90 天以前的记录或清空全部记录。
- 访问统计新增“解析登录用户”下级页面，记录成功登录用户、时间、入站、IP 和设备，并支持删除与分时段清理。
- 用户打开网站并通过本地缓存自动恢复登录成功时，同样记录到“解析登录用户”，不再仅记录手动点击登录。
- 微信、QQ 内置浏览器打开网站时显示外部浏览器指引，并提供当前网址一键复制。

生产环境迁移或重装 Caddy 时，请按照 [INFRASTRUCTURE.md](INFRASTRUCTURE.md) 恢复网站的
`/supabase` 同源反向代理。该路由是用户登录、管理员登录、订单查询和实时流量功能的必要依赖。
