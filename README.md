# 节点商城 3.0

> 最后更新日期：2026-11-18

## 最近更新

- 面板对接新增手动主副面板同步。选择已启用的面板和对应入站，预览后可将匹配 UUID 的启用状态、到期时间及流量上限同步到副面板。

- 新增管理员后台访问统计，支持真实访客 IP、访问时间、停留时间、页面名称、来源和设备信息。
- 访问统计数据及停留时间每 15 秒自动刷新。
- 修复 Cloudflare 与 VPS 反向代理场景下访客 IP 被记录为服务器 IP 的问题。
- 修复着陆页顶部外部图床链接在部分网络环境无法显示的问题，改为网站同源安全代理加载。
- 访问统计新增单条记录删除功能；补充 sitemap、canonical 与搜索引擎抓取规则。
- 管理员登录页和后台不再加载或显示悬浮在线客服组件。
- 优化着陆页搜索标题、描述、核心关键词和结构化数据，并接入 IndexNow 主动提交。
- 添加百度搜索资源平台首页所有权验证标签。
- 添加搜狗站长平台首页所有权验证标签。
- 添加神马搜索站长平台首页所有权验证标签。
- 访问统计清理支持选择 7、30、90 天以前的记录或清空全部记录。
- 访问统计新增“解析登录用户”下级页面，记录成功登录用户、时间、入站、IP 和设备，并支持删除与分时段清理。
- 用户打开网站并通过本地缓存自动恢复登录成功时，同样记录到“解析登录用户”，不再仅记录手动点击登录。
- 微信、QQ 内置浏览器打开网站时显示外部浏览器指引，并提供当前网址一键复制。

生产环境迁移或重装 Caddy 时，请按照 [INFRASTRUCTURE.md](INFRASTRUCTURE.md) 恢复网站的
`/supabase` 同源反向代理。该路由是用户登录、管理员登录、订单查询和实时流量功能的必要依赖。
